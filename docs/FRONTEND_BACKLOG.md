## Блок 1 — вертикальный срез. КРИТИЧЕСКИЙ ПУТЬ

Рубеж сформулирован бэкендером в [BACKLOG.md](BACKLOG.md): **«зашёл на сайт,
залогинился, увидел свой профиль и список новостей»**. Бэкенд для этого готов,
доделывать там нечего.

Пока среза нет, каждый тикет бэкенда пишется вслепую, а каждая наша страница —
против выдуманного контракта. Ничего из блоков 2–4 начинать раньше нельзя.

Порядок внутри блока менять нельзя: F-11 стоит на F-10, F-12 на обоих.

| Тикет | Что | Оценка |
|---|---|---|
| ~~F-10~~ | **API-клиент.** Один экземпляр axios: `baseURL` из `import.meta.env`, `Authorization: Bearer`, разбор ошибок RFC 9457 (включая словарь `errors` у валидации), обработка 401 → стереть токен → на логин. Отдельно решить, где живёт JWT: `localStorage` просто, но уязвим к XSS; память + httpOnly refresh-cookie правильнее, но требует ручки на бэкенде (она в T-30) | ✅ 2026-08-26 |
| ~~F-11~~ | **Контракт в типах.** Перенести доменные модели из `shared/types/models/` старого проекта — это ~550 готовых строк, придумывать заново нечего. Классы с конструкторами превратить в `type`: инстансы классов ломают structural sharing в TanStack Query. Добавить спринговую `Page<T>` (`content`, `page`, `size`, `totalElements`, `totalPages`, счёт страниц с нуля). **Починить `auth.types.ts`** — там до сих пор джанговские `pk`, `email`, `isSuperuser`, `isModerator`, `isAnonymous`, `isStaff`, а контракт требует `id`, `username`, `superuser`, `moderator` без префикса `is` | ✅ 2026-08-26 |
| F-12 | **Авторизация по-настоящему.** `useAuth` с моков на TanStack Query: `POST /api/users/auth/login` → `{accessToken}`, профиль через `GET /api/users/profile`, `useQuery(['profile'])` вместо `useState` в хуке. Серверного logout в контракте нет — выход только локальный. Страница входа на `react-hook-form` + `zod` | вечер-два |
| F-13 | **Профиль.** `/corp/personal` — карточка и смена пароля (`POST /api/users/change-password`), ошибки полей из словаря `errors` | вечер |
| F-14 | **Новости.** `GET /api/public/news` со спринговой пагинацией, список и детальная. Это **эталонный модуль**: в старом коде `posts-base.service.ts` был общим предком новостей, анонсов, конференций и достижений — паттерн, отработанный здесь, закрывает потом 8 роутов | вечер-два |

**Готово когда** — на чистом браузере можно залогиниться реальным аккаунтом,
увидеть своё имя в шапке, открыть профиль, сменить пароль и пролистать новости
с реального бэкенда. Расхождения контракта с реальностью — issue с меткой
`frontend`, а не сообщение в чат.
